# Attendance System

This repository contains a premium web-based camera application designed for the attendance system.

## Features
- Modern UI with glassmorphism.
- Real-time camera streaming.
- Integrated controls for starting and stopping the feed.

## Setup
Simply open `index.html` in a modern web browser.

**Live:** https://makerworkslab.in/attendance/
